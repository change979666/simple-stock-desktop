# 发货管理物流单号显示修复

## 问题
导入发货时填写了物流单号，但界面上不显示。

## 原因
`gui/shipment_view.py` 的 `display_shipments_from_result()` 方法中，SKU子项没有设置物流单号到第2列（物流单号列）。

## 修复
在第510行添加物流单号显示：

```python
# 修复前
sku_item.setText(0, f"  └─ {sku}")
sku_item.setText(1, str(quantity))
sku_item.setText(3, status_text)      # ❌ 跳过了第2列
sku_item.setText(4, time_text)

# 修复后
sku_item.setText(0, f"  └─ {sku}")
sku_item.setText(1, str(quantity))
sku_item.setText(2, tracking)         # ✅ 添加物流单号
sku_item.setText(3, status_text)
sku_item.setText(4, time_text)
```

## 验证结果
数据库中保存了完整的物流单号数据：
- BD20251122批次：40个SKU，物流单号 `YD20251122`
- BD20251119批次：7个SKU，物流单号 `YD20251119`
- BD20251108批次：50个SKU，物流单号 `YD20251108`
- BD251017批次：57个SKU，物流单号 `YD20250100017`

现在界面上会正确显示物流单号了！
