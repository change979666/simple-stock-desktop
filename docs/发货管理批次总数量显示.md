# 发货管理批次总数量显示功能

## v5.0.0 更新说明

### 功能简介

在发货管理界面中，每个发货批次现在会自动显示该批次的**总发货数量**，方便用户快速查看发货规模。

### 实现方式

**客户端自动计算** - 使用前端算法实时计算，无需修改数据库结构。

### 显示效果

发货管理表格列：

| 批次/SKU | **数量** | 物流单号 | 状态 | 发货时间 | 操作 |
|---------|---------|---------|------|---------|------|
| 📦 BD20251122 | **6445** | - | 🚚 运输中 | 2025-11-23 | [操作按钮] |
| └─ BD05-Camel | 240 | SF123... | 🚚 运输中 | 2025-11-23 | |

| └─ BD53-Coffee-110CM | 120 | SF123... | 🚚 运输中 | 2025-11-23 | |
| ... | ... | ... | ... | ... | |

### 核心代码

```python
# 计算批次总数量
shipment_items = get_attr(shipment, 'shipment_items', [])
total_quantity = sum(
    get_attr(item, 'quantity', 0) for item in shipment_items
)
batch_item.setText(1, str(total_quantity))

# 数量列加粗显示
font_bold = QFont()
font_bold.setBold(True)
batch_item.setFont(0, font_bold)
batch_item.setFont(1, font_bold)  # 数量列也加粗
```

### 技术细节

1. **数据来源**：从 `shipment.shipment_items` 聚合计算
2. **显示格式**：批次行显示总数量，子项显示各SKU数量
3. **样式优化**：批次行数量使用粗体，便于区分
4. **性能优化**：使用已加载的数据，无额外查询

### 使用场景

1. **快速统计** - 一眼看出每批次发货量
2. **批次对比** - 方便比较不同批次的规模
3. **库存规划** - 辅助判断在途库存总量

### 注意事项

- 数量统计为**实时计算**，自动包含所有SKU明细
- 展开批次可查看每个SKU的具体数量
- 删除SKU明细会自动更新批次总数量
- 数量为0的批次也会正常显示"0"
