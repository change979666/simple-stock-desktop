# 发货管理运输方式图标功能

## 功能说明

在发货管理界面的"运输中"状态，根据物流单号自动识别运输方式并显示对应图标。

## 运输方式识别规则

### 物流单号前缀识别

| 前缀 | 运输方式 | 图标 | 示例 |
|------|---------|------|------|
| **YD** | 海运 | 🚢 | YD20251122 |
| **TA** | 海运 | 🚢 | TA20251201 |
| **TB** | 陆运 | 🚚 | TB20251201 |
| 其他 | 陆运(默认) | 🚚 | SF1234567890 |

### 状态显示示例

```
状态列显示:
- 🚢 运输中(海运)  ← YD/TA开头的物流单号
- 🚚 运输中(陆运)  ← TB开头的物流单号
- ⏳ 待发货
- 📦 已到达
- ✅ 已上架
- ❌ 已取消
```

## 实现细节

### 核心函数

```python
def get_transport_icon(tracking_number: str) -> str:
    """根据物流单号返回运输图标"""
    if tracking_number.startswith(('YD', 'TA')):
        return '🚢'  # 海运
    elif tracking_number.startswith('TB'):
        return '🚚'  # 陆运
    else:
        return '🚚'  # 默认陆运

def get_transport_method_text(tracking_number: str) -> str:
    """根据物流单号返回运输方式文本"""
    if tracking_number.startswith(('YD', 'TA')):
        return '海运'
    elif tracking_number.startswith('TB'):
        return '陆运'
    else:
        return '陆运'
```

### 显示逻辑

在 `display_shipments_from_result()` 方法中：

```python
if status_str == 'in_transit':
    # 获取第一个物流单号判断运输方式
    first_tracking = shipment_items[0].tracking_number
    transport_icon = get_transport_icon(first_tracking)
    transport_text = get_transport_method_text(first_tracking)
    status_text = f"{transport_icon} 运输中({transport_text})"
```

## 使用说明

### 1. 导入发货记录

Excel文件中填写物流单号时，使用正确的前缀：

| sku | quantity | tracking_number | estimated_arrival |
|-----|----------|----------------|-------------------|
| BD05-Camel | 240 | **YD**20251122 | 2025-12-01 |
| BD10-Black | 600 | **TB**20251201 | 2025-12-05 |
| BD20-White | 300 | **TA**20251215 | 2025-12-20 |

### 2. 查看运输方式

在发货管理界面，"状态"列会自动显示：
- 🚢 运输中(海运) - YD/TA开头
- 🚚 运输中(陆运) - TB开头或其他

### 3. 筛选运输方式

可以在状态筛选中选择"🚚 运输中"查看所有在途订单，系统会自动区分海运和陆运。

## 注意事项

1. **物流单号大小写不敏感**：yd、YD、Yd 都会识别为海运
2. **空物流单号默认陆运**：如果未填写物流单号，默认显示陆运图标
3. **批次运输方式统一**：根据批次中第一个SKU的物流单号判断整个批次的运输方式
4. **已上架/已取消不显示运输图标**：只有"运输中"状态才显示运输方式
