## 功能概述

本次更新为库存管理系统增加了两个重要功能：

### 1. 📤 库存数据导出
- 一键导出所有库存数据到Excel文件
- 包含完整的库存、销量、在途库存等信息
- 支持自定义文件名和保存位置

### 2. 🚚 在途库存显示
- 实时显示正在发货途中的库存数量
- 自动同步发货管理系统数据
- 上架入库后自动清零

## 导出库存数据

### 使用步骤

1. **打开库存管理页面**
   - 点击主界面的"库存管理"标签

2. **点击导出按钮**
   - 在工具栏找到"📤 导出"按钮（位于"批量修改"按钮右侧）
   - 点击该按钮

3. **选择保存位置**
   - 系统会弹出文件保存对话框
   - 默认文件名：`库存数据_YYYYMMDD_HHMMSS.xlsx`
   - 选择合适的保存位置，点击"保存"

4. **查看导出结果**
   - 导出成功后会显示确认消息
   - 消息中包含文件保存路径

### 导出文件内容

导出的Excel文件包含以下列：

| 列名 | 说明 |
|------|------|
| 父SKU | 产品的父级SKU编码 |
| 子SKU | 产品变体的SKU编码 |
| 库存 | 当前实际库存数量 |
| 预警 | 库存预警阈值 |
| 在途库存 | 发货途中的数量 |
| 状态 | 库存状态（正常/库存不足/无库存） |
| 今日销量 | 今天的销售数量 |
| 昨日销量 | 昨天的销售数量 |
| 7天销量 | 最近7天的销售总量 |
| 30天销量 | 最近30天的销售总量 |
| 今年销量 | 今年的销售总量 |

### 应用场景

- ✅ 定期备份库存数据
- ✅ 制作库存报表
- ✅ 数据分析和统计
- ✅ 与其他系统对接
- ✅ 打印库存清单

## 查看在途库存

### 功能说明

**在途库存**是指正在运输途中、尚未到达仓库的商品数量。只统计以下状态：
- 🚚 运输中（in_transit）

**注意**：待发货状态不计入在途库存

### 查看方式

1. **在库存管理页面查看**
   - 在途库存显示在"预警"和"状态"列之间
   - 第4列：在途库存

2. **颜色标识**
   - 🔵 **蓝色粗体**：有在途库存（数量 > 0）
   - ⚪ **灰色**：无在途库存（数量 = 0）

### 数据来源

在途库存数据来自**发货管理**模块：
- 只统计状态为"🚚 运输中"的发货单
- 自动汇总同一SKU的所有运输中数量
- 每次刷新库存数据时自动更新

### 示例

假设发货管理中有以下记录：

| SKU | 数量 | 状态 |
|-----|------|------|
| BD99-Black | 50 | 待发货 |
| BD99-Black | 150 | 🚚 运输中 |
| BD99-Black | 20 | 已上架 |

则在库存管理中，`BD99-Black`的在途库存显示为：**150件**（只统计运输中状态）

## 上架入库操作

### 操作步骤

1. **打开发货管理页面**
   - 点击主界面的"发货管理"标签

2. **找到需要上架的发货单**
   - 查看状态为"运输中"或"待发货"的发货单
   - 确认货物已经到达

3. **点击上架入库按钮**
   - 点击发货单右侧的"✅ 上架入库"按钮
   - 确认操作

4. **验证结果**
   - 发货单状态变更为"已上架"
   - 切换到库存管理页面
   - 相关SKU的在途库存自动变为0

### 状态流转

```
⏳ 待发货 (pending) ← 不计入在途库存
    ↓
🚚 运输中 (in_transit) ← 计入在途库存 ✅
    ↓
📦 已到达 (arrived) ← 不计入在途库存
    ↓
✅ 已上架 (shelved) ← 不计入在途库存，此时在途库存清零
```

### 自动化处理

系统会自动处理以下事项：
1. ✅ 更新发货单状态
2. ✅ 清除库存数据缓存
3. ✅ 重新计算在途库存
4. ✅ 更新库存管理页面显示

## 常见问题

### Q1: 为什么导出失败？
**A**: 可能的原因和解决方法：
- 检查是否安装了`openpyxl`库：`pip install openpyxl`
- 确保有足够的磁盘空间
- 检查保存路径是否有写入权限
- 关闭已打开的同名Excel文件

### Q2: 在途库存不准确怎么办？
**A**: 尝试以下操作：
1. 点击"🔄 刷新数据"按钮
2. 检查发货管理中的发货单状态是否正确
3. 确认是否有发货单状态为"🚚 运输中"

### Q3: 上架入库后在途库存没有清零？
**A**: 检查以下几点：
1. 确认上架操作是否成功完成
2. 刷新库存管理页面（点击"刷新数据"）
3. 检查发货单状态是否确实变为"已上架"

### Q4: 导出的Excel文件打不开？
**A**: 可能的原因：
- Excel版本过低，建议使用Excel 2010或更高版本
- 文件可能损坏，尝试重新导出
- 检查文件扩展名是否为`.xlsx`

### Q5: 在途库存包括哪些状态的发货单？
**A**: 
- ✅ **只包括**：运输中（in_transit）
- ❌ **不包括**：待发货、已到达、已上架、已取消

### Q6: 可以只导出部分数据吗？
**A**: 
- 当前版本导出全部显示的库存数据
- 可以先使用搜索功能筛选，再导出
- 搜索后导出的数据仅包含搜索结果

### Q7: 导出数据的顺序是什么？
**A**: 
- 按照界面显示的顺序导出
- 父SKU按字母顺序排序
- 子SKU在各自父SKU下按字母顺序排序

## 💡 使用技巧

### 技巧1: 定期导出备份
建议每周或每月导出一次库存数据作为备份：
```
文件命名示例：
- 库存备份_2024年11月_第1周.xlsx
- 库存备份_2024年11月_月末.xlsx
```

### 技巧2: 利用在途库存做采购决策
公式：`安全库存 = 当前库存 + 在途库存 - 预期销量`

### 技巧3: 搜索后导出
1. 输入SKU关键字搜索
2. 点击导出按钮
3. 只导出搜索结果，更精确

### 技巧4: 批量查看在途库存
在途库存列支持排序：
- 点击列标题可按数量排序
- 快速找出在途库存最多的SKU
